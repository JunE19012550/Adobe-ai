เรียนรู้ Adobe Illustrator ตั้งแต่ศูนย์

เว็บสื่อการสอนแบบคลีนๆ ที่ช่วยให้คุณเข้าใจหลักการออกแบบเวกเตอร์ เครื่องมือพื้นฐาน คีย์ลัดสำคัญ พร้อมเครื่องมือทดลองปฏิสัมพันธ์แบบจำลองจริง

1. เข้าใจ Vector vs Raster

หัวใจสำคัญที่ทำให้ Illustrator แตกต่างจาก Photoshop

Vector (Illustrator)

กราฟิกสมการคณิตศาสตร์

สร้างจากจุด (Anchor Point) และเส้น (Path) ไม่ว่าจะขยายใหญ่เท่าตึกหรือย่อเล็กเท่าแสตมป์ **ภาพจะไม่แตกและคมชัดสมบูรณ์เสมอ** เหมาะกับงานโลโก้ ไอคอน และสิ่งพิมพ์

ขยาย 1000% (ชัดแจ๋ว)
Raster (Photoshop)

กราฟิกพิกเซล (Pixel)

ประกอบขึ้นจากจุดสีตารางเล็กๆ ยิ่งขยายภาพ ความละเอียดพิกเซลจะแตกเป็นตารางสี่เหลี่ยม เหมาะกับงานภาพถ่าย หรืองานที่มีรายละเอียดเฉดสีซับซ้อน

ขยายใหญ่ขึ้น (เห็นพิกเซลแตก)

2. เครื่องมือหลักที่ต้องใช้งานให้เป็น

กล่องเครื่องมือ (Toolbox) พื้นฐานที่จะเจอบ่อยที่สุด

V

Selection Tool

คีย์ลัด: V

ใช้สำหรับคลิกเลือกวัตถุ เคลื่อนย้าย ปรับขนาด หรือย่อ/ขยายรูปทรงโดยรวม

A

Direct Selection Tool

คีย์ลัด: A

ใช้คลิกเลือกเฉพาะจุด Anchor Point หรือเส้น Path เดี่ยวๆ เพื่อดัดแปลงโครงสร้างรูปทรง

P

Pen Tool

คีย์ลัด: P

เครื่องมือทรงพลังที่สุดสำหรับวาดเส้นโค้ง อิสระ และสร้างเวกเตอร์รูปทรงแปลกใหม่

M

Shape Tools

คีย์ลัด: M / L

เครื่องมือสร้างรูปทรงพื้นฐาน สี่เหลี่ยม (M), วงกลม (L), และดาว เพื่อนำมาประกอบเป็นงานกราฟิก

3. โหมดสีที่ต้องเลือกให้ถูกต้อง (RGB vs CMYK)

ตั้งค่าสีให้เหมาะกับปลายทางของงาน

RGB Color Mode

ใช้สำหรับ **งานแสดงผลบนหน้าจอ** (Digital Screen, เว็บไซต์, แอปพลิเคชัน, สื่อ โซเชียลมีเดีย) สีจะสดใสสว่างกว่า

Document Profile: Web / Mobile / Screen

CMYK Color Mode

ใช้สำหรับ **งานสิ่งพิมพ์** (Print, โบรชัวร์, นามบัตร, ป้ายไบนิล, บรรจุภัณฑ์) สีจะดูอิ่มและตรงกับหมึกพิมพ์จริง

Document Profile: Print / Press

เครื่องมือจำลอง Pathfinder

Pathfinder คือการตัด ดึง หรือผสานรูปทรงมากกว่า 2 ชิ้นเข้าด้วยกัน เพื่อสร้างเชปใหม่ ทดลองกดปุ่มด้านล่างเพื่อสังเกตผลลัพธ์ของการดัดแปลง SVG สองชิ้น!

คำสั่งปัจจุบัน: ต้นฉบับ (ยังไม่รวมรูปทรง)

ห้องปฏิบัติการฝึก Bezier Curve (Pen Tool)

ลองลากจุดควบคุม (Direction Handle) เพื่อเรียนรู้ว่าแนวแรงกระทำและมุมก้านแฮนเดิล ส่งผลต่อความโค้งของเส้นเวกเตอร์อย่างไร!

จุด Handle (ลากเพื่อดัดเส้น) เส้น Path เวกเตอร์จริง

คีย์ลัดที่ต้องรู้ (Shortcuts Cheat Sheet)

ช่วยให้คุณทำงานกราฟิกได้เร็วขึ้นเป็น 2 เท่า

Step-by-step Hands-on

เวิร์กชอป: สร้างโลโก้รูปนกด้วย Shapes & Pathfinder

เรียนรู้ขั้นตอนจริงในการออกแบบกราฟิกเวกเตอร์ง่ายๆ ด้วยการนำรูปทรงพื้นฐานมาดัดแปลง

1

สร้างวงกลม 2 วงเหลื่อมกัน

กดเครื่องมือ Ellipse Tool (L) จากนั้นกด Shift ค้างไว้แล้วลากเพื่อสร้างวงกลมสมบูรณ์แบบ วาด 2 วงให้มีขนาดต่างกันแล้ววางเหลื่อมซ้อนกัน

2

ใช้ Pathfinder ตัดส่วนเกิน

คลุมเลือกวงกลมทั้งสองด้วย Selection Tool (V) แล้วเปิดพาเนล Pathfinder กดปุ่ม Minus Front เพื่อตัดวงกลมบนออก ได้รูปทรงเสี้ยวจันทร์สวยงาม

3

ใส่สีแบบ Gradation (ไล่เฉดสี)

เปิดพาเนล Gradient (Ctrl + F9) เลือกโทนสีส้มไปเหลือง เพื่อเพิ่มมิติความนูนและความทันสมัยให้กับโลโก้

4

ใส่ชื่อแบรนด์ด้วย Type Tool

กดเครื่องมือ Type Tool (T) พิมพ์ชื่อแบรนด์ด้านข้าง ปรับฟอนต์ให้โมเดิร์น แล้วกดจัดวางองค์ประกอบให้สมดุล
